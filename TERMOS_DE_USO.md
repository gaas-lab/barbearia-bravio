# Termos de Uso — Barbearia Bravio

**Versão de trabalho — 25 de outubro de 2026.** Este texto é um rascunho informativo baseado nas funcionalidades atualmente identificadas. Deve ser revisado pelo operador da instância antes de publicação ou apresentação para aceite.

## 1. Sobre o sistema

O Barbearia Bravio é um software de apoio à organização de agenda, serviços, equipe e registros financeiros de uma barbearia. A aplicação pode funcionar localmente em um navegador ou com serviços em nuvem, conforme a instalação.

Na instância oficial hospedada, a operação é realizada por **Gaaslab**. O canal de contato é [gaasbrel@gmail.com](mailto:gaasbrel@gmail.com). A identificação jurídica completa do operador deve ser acrescentada antes da publicação de uma versão definitiva.

## 2. Acesso e responsabilidades

O gerente administra a barbearia, os convites e os acessos da equipe. Cada usuário deve proteger suas credenciais, manter seus dados atualizados e avisar o administrador se suspeitar de acesso indevido.

Quem administra uma barbearia é responsável por inserir dados de clientes e profissionais apenas para finalidades legítimas, informar as pessoas envolvidas, definir permissões adequadas e responder aos pedidos relacionados aos dados sob seu controle. Não insira dados sensíveis em campos livres quando não forem necessários.

## 3. Registros e cálculos

Agenda, serviços, comissões, despesas e demais valores dependem dos dados inseridos e das configurações feitas pela barbearia. O sistema é uma ferramenta operacional e não substitui contabilidade, folha de pagamento, orientação jurídica, fiscal ou trabalhista, nem constitui registro certificado de jornada de trabalho. Confira os dados e mantenha os registros oficiais exigidos para a atividade.

## 4. Armazenamento e disponibilidade

No modo local, os dados ficam no navegador e podem ser perdidos se o armazenamento for apagado, o perfil do navegador for removido ou o dispositivo falhar. No modo em nuvem, os dados dependem dos serviços de autenticação, banco de dados e hospedagem configurados pela instância. O operador deve publicar informações precisas sobre fornecedores, retenção, cópias de segurança e disponibilidade.

## 5. Uso permitido

O usuário deve usar o sistema conforme a lei, respeitar direitos de clientes e profissionais e não tentar acessar dados de outras barbearias, contornar controles de acesso ou comprometer a aplicação. O gerente deve remover acessos que já não sejam necessários e revisar periodicamente as permissões.
